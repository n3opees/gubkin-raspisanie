# Расписание Губкина — Android

Приложение с виджетом для рабочего стола. Виджет показывает пары на сегодня, а после последней пары — на следующий учебный день. В самом приложении сверху ряд Пн–Вс: нажми на день, чтобы посмотреть его пары. Ряд можно смахнуть влево-вправо (или нажать стрелки ‹ ›), чтобы листать недели до конца семестра. Кнопка «Сегодня» справа вверху возвращает к сегодняшнему дню. Подходит для любой группы РГУ нефти и газа. Работает само: заходить в приложение каждый раз не нужно.

## Установка

1. Скачай **gubkin-raspisanie.apk** со страницы [Releases](../../releases/latest) на телефон и открой его.
2. Android спросит, можно ли устанавливать приложения из этого источника (Telegram, браузер, «Файлы»). Разреши и нажми «Установить».
   Приложение не из Google Play, поэтому система может показать предупреждение — это нормально.
3. Открой «Расписание Губкина», введи логин и пароль от lk.gubkin.ru и свою группу (например, ГМ-24-11). Нажми «Войти и загрузить расписание».
4. Нажми «Добавить виджет на рабочий стол». Если кнопки нет: зажми пустое место на рабочем столе → «Виджеты» → «Расписание Губкина».

Логин хранится только в памяти телефона, пароль — в зашифрованном виде (ключ в защищённом хранилище Android). Приложение отправляет их только на сайт личного кабинета.

## Как работает

- Расписание берётся с lk.gubkin.ru через невидимый встроенный браузер: прямые запросы из программ сервер университета тормозит, а браузер пускает.
- При входе скачивается весь семестр — от текущей недели до конца (прошедшие недели сайт студентам не показывает). Недели качаются по одной с паузами; весь семестр перекачивается раз в неделю, текущая и следующая неделя — каждые несколько часов. Виджет рисует пары из сохранённых данных, без интернета.
- Виджет перерисовывается после последней пары (переключается на следующий день) и в полночь. Свежие данные из интернета — не чаще раза в 3 часа, плюс фоновое обновление раз в несколько часов.
- Если телефон экономит батарею, Android может сдвинуть обновление на несколько минут.

## Если что-то не так

- «Сервер расписания временно ограничил доступ» — подожди пару часов, не нажимай «Обновить» много раз подряд.
- Виджет пишет «Обновлено N дн назад» — открой приложение, оно обновится само.
- Сменить группу или логин — кнопка «Сменить группу или логин» в приложении.

## Для разработки

Собирается без Android Studio, напрямую инструментами Android SDK:

```sh
sh build.sh                  # обычная сборка → gubkin-raspisanie.apk
DEBUG=1 sh build.sh          # отладочная (можно читать данные приложения через adb run-as)
node tools/test-logic.js     # проверка логики работы с сайтом (app/assets/logic.js)
sh tools/test-daypicker.sh   # проверка выбора дня и времени обновления
sh tools/emu-login.sh        # вход на запущенном эмуляторе с данными из ../login.txt
```

Инструменты (Java 17, Android SDK, эмулятор) лежат в `%USERPROFILE%\.gubkin-android-tools`.

**Ключ подписи `signing/gubkin.keystore` в репозиторий не входит** (он в `.gitignore`) — храни его у себя и не теряй: им подписан APK. Новые версии встанут поверх старой только с тем же ключом. Перед выпуском новой версии увеличь `VERSION_CODE` в `build.sh`.

| Файл | Что делает |
|---|---|
| `app/assets/logic.js` | Вход, поиск группы, разбор расписания — выполняется внутри страницы кабинета |
| `WebFetcher.java` | Невидимый браузер: открывает кабинет и запускает logic.js |
| `Sync.java` | Первая настройка и обновление расписания |
| `ScheduleWidget.java` | Виджет и будильник перерисовки |
| `RefreshJob.java` | Фоновое обновление из интернета |
| `DayPicker.java` | Какой день показать и когда перерисовать |
| `Store.java` | Хранение логина, зашифрованного пароля, группы и расписания |
| `MainActivity.java` | Экран приложения |
